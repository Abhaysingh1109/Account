# Project Note: Accounting Dashboard

## What I Do In This Project
I built an interactive accounting dashboard that takes business transaction data from a CSV file and turns it into clear financial insights. My work in this project includes:

- Building data ingestion and cleaning logic for accounting records.
- Detecting important columns automatically (date, amount, type, category, customer, receivable, payable).
- Creating monthly financial summaries such as revenue, expenses, profit, and net cash flow.
- Designing visual analytics for trends, expense breakdowns, receivables/payables, and top customers.
- Generating practical business recommendations from the processed data.
- Exporting an additional web dashboard (HTML + CSS + Chart.js) from the same processed dataset.

## Technologies Used
- Python: Core programming language.
- Streamlit: Main framework for the interactive dashboard UI.
- Pandas: Data cleaning, transformation, and aggregation.
- NumPy: Numeric operations and calculations.
- Plotly (Express + Graph Objects): Charts and interactive visualizations.
- HTML/CSS/JavaScript: Generated web dashboard interface.
- Chart.js: Charts in exported web dashboard files.

## Motive Of The Project
The main motive is to help small and medium businesses quickly understand their financial health without manual spreadsheet analysis. This project makes accounting data easier to read and act on by:

- Showing business performance month by month.
- Highlighting profit trends and cash flow position.
- Surfacing spending concentration and receivable/payable risks.
- Supporting better and faster financial decision-making.

## Project Outcome
This dashboard converts raw accounting data into a decision-support tool. Instead of just storing transactions, it helps users identify problems, track growth, and plan next actions.
